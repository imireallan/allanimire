# Vercel deployment

This is a Vite + React portfolio/resume site deployed on Vercel.

## Recommended setup

Use Vercel as the primary portfolio host.

1. Push this repository to GitHub.
2. In Vercel, import `imireallan/allanimire`.
3. Framework Preset: `Vite`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. Install Command: `npm install`.
7. Set/rename the Vercel project to `allanimire` so the production URL is `https://allanimire.vercel.app/`.

## Public URLs

Primary portfolio:

```text
https://allanimire.vercel.app/
```

Direct resume PDF:

```text
https://allanimire.vercel.app/resume.pdf
```

ATS-readable resume text:

```text
https://allanimire.vercel.app/resume.md
```

## Repo and project naming

- GitHub repository: `imireallan/allanimire`
- Vercel project: `allanimire`
- Public URL: `https://allanimire.vercel.app/`

Keep these aligned so resume links stay short, stable, and easy to paste into applications.
