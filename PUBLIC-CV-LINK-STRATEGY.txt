Important setup:
1. Push this repo to GitHub.
2. In GitHub, go to Settings → Pages.
3. Set Source to "Deploy from a branch".
4. Choose branch `main` and folder `/root`.
5. Save.
6. Wait 1–3 minutes, then test both links in an incognito/private browser.

If GitHub Pages is already enabled, only pushing the changes is needed.
